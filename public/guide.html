Getting Started

1. Create Your Personal Room

On the main page, click Create Personal Scoreboard.

After the room is created, you should be automatically redirected to it.

⚠️ Important: There is no need to create a new room every time. One room per user is more than enough and helps save space in the database.

2. If You Were Not Redirected Automatically

There are two buttons on the main page that allow you to access your existing room:

  1. Open Existing Room
  2. Find Existing Room

Use either option to open your previously created room.

3. Widget Management

A separate video guide is provided that explains all widget controls and available settings.

Watch on YouTube ↗

4. Adding Widgets to OBS

To add a widget to OBS:

  1. Open the desired widget page in your browser.
  2. Copy the URL from the browser's address bar.
  3. In OBS, create a new Browser Source.
  4. Paste the copied URL into the source settings.

5. Resizing Widgets

The width of the Browser Source in OBS can be adjusted freely.

As the width changes, the widget layout will automatically adapt to fit the available space and maintain a clean appearance.

Using Personal Widgets

To use personal widgets, you need to manually modify the URL of any free widget.

Simply replace the ending .../default with your personal room identifier, which will be created and sent to you individually.

That's it. Once updated, the widget will display data from your personal room instead of the default one.

Як почати користуватися сервісом

1. Створіть власну кімнату

На головній сторінці натисніть Create Personal Scoreboard.

Після створення вас автоматично перенаправить у щойно створену кімнату.

⚠️ Важливо: Не потрібно щоразу створювати нову кімнату. Однієї кімнати на користувача більш ніж достатньо. Це також допомагає економити місце в базі даних.

2. Якщо автоматичне перенаправлення не спрацювало

На головній сторінці доступні дві кнопки для входу у вашу кімнату:

  1. Open Existing Room
  2. Find Existing Room

Використайте будь-яку з них, щоб відкрити вже створену кімнату.

3. Керування віджетами

Окремо додано відео-інструкцію, в якій показано всі основні можливості та налаштування віджетів.

Дивитися на YouTube ↗

4. Додавання віджетів в OBS

Щоб додати віджет в OBS:

  1. Відкрийте сторінку потрібного віджета в браузері.
  2. Скопіюйте URL-адресу зі свого браузера.
  3. В OBS створіть нове джерело типу Browser.
  4. Вставте скопійоване посилання в налаштування джерела.

5. Налаштування розміру

Ширину браузерного джерела в OBS можна вільно змінювати.

При зміні ширини дизайн віджетів автоматично адаптується під новий розмір для більш коректного відображення.

Використання персональних віджетів

Для використання персональних віджетів необхідно вручну змінити посилання будь-якого безкоштовного віджета.

Все дуже просто: замість частини URL .../default необхідно підставити свій персональний ідентифікатор кімнати, який буде створений та надісланий вам особисто.
